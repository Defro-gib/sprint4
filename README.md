Sprint 4 Project 
Vehicle Listings Analysis Tool
Project Overview
This project is a Streamlit web application designed to analyze and visualize data on used vehicle listings. The purpose of the tool is to give users insights into how long vehicles have been listed for sale, their model years, and other relevant details. Through this interactive app, users can explore patterns in the dataset and gain a better understanding of the vehicle listings' dynamics over time.

Key Features
Scatter Plot: Visualizes the relationship between the number of days a vehicle has been listed and its model year, with color coding for vehicle types.
Histogram: Shows the distribution of the number of days that vehicles have been listed, helping users understand typical listing durations.
Interactive Filters: A checkbox allows users to modify displayed data based on their preferences, making the visualizations more customizable.
Libraries Used
Streamlit: Used to build and deploy the interactive web application, allowing for a user-friendly and responsive interface.
Pandas: Employed for data manipulation and preprocessing, enabling efficient loading and handling of the dataset.
Plotly Express: Generates interactive scatter plots and histograms, adding visual clarity and detail to the dataset analysis.
